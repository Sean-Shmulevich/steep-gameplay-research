# Next bounded binary trace

Trace the compiled DataNode's source-field conversion into its embedded handle, then identify the immediate authored producer of that source field. Do this offline before any observation proposal.

Start with the exact handle initializer called by the virtual clone. The call passes destination handle, source node's 64-bit resource-source field, and zero. Export that helper and follow only the assignment that establishes the handle's provider comparison key. A UID-shaped argument is insufficient. The success condition is an explicit value lineage into the key compared by the existing replacement resolver.

Then follow the concrete producer that writes the compiled source field. Use the runtime descriptor's one member record and the class distinction in the current receipts. The input witness remains the exact idle Atom owned output at graph byte 3,092,637, with resource UID at byte 3,092,677. The conversion must consume that UID field through a verified source grammar. It must not substitute the neighboring output GUID or treat a compiled offset as an archive offset.

Exact addresses and byte locations are in [private/NEXT_TRACE.md](trace-recipe.md). Cap the follow-up to four function candidates, each at most 24,000 pdata-linked bytes, and at most 24 member or descriptor candidates. Read the helper first and choose dependent candidates from its actual assignments. Stop if the required authored grammar is unavailable, if no source-field writer is found within this bound, or if the helper resolves another opaque object without an inspectable key assignment. Preserve both unresolved edges rather than claiming a generic copy as success.

Expected discriminating results are an identity copy, a transformed lookup key, or an opaque indirection. An identity copy closes only the compiled-field-to-key edge. A transformed key needs its exact transform and source interpretation. Opaque indirection leaves the key unresolved. Full success requires a receipt connecting the known idle UID to the compiled field and the resulting handle key.

No live experiment is proposed here. The pointer ownership required for safe actor/controller discovery remains open. Landing selection may follow only after both resource-binding assignments are proved.
